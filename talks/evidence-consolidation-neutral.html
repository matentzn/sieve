Evidence models across Monarch repositories

Current representation of evidence, two consolidation options, migration examples.

Context

A growing share of assertions is machine-generated

  • Assertions increasingly enter the knowledge bases via extraction, synthesis, and drafting, not manual authoring.
  • AI-assisted pipelines already in the ecosystem: DisMech, deep-research artifact ingestion.
Part I

Current state

Two functions of "evidence"

Two records, one name

Scientific evidence

Does a source support or refute the claim?

reference, snippet, direction, ECO code

Provenance / attribution

What produced the statement, from where?

agent / method, source, knowledge level

  • Manual curation: provenance is implicit — the curator's identity.
  • Machine-generated statements carry no implicit attribution; the fields above are the explicit record.

Part II

Consolidation options

The choice

One goal, three ways

Goal: stop each repository inventing its own evidence model.

A

One rich standard

Everyone conforms to a single expressive model (SEPIO). Most powerful, most work.

B

One small class

Everyone imports the same tiny evidence class. Covers the common case, easy to adopt.

C

Own model, then map

No shared model. Each system is mapped to a reference and scored for completeness. Least coordination, most ongoing mapping.

Open question · dismech #5000

Level of evidence (study strength)

  • Optional evidence_level slot — GRADE (HIGH/MODERATE/LOW/VERY_LOW) or Oxford CEBM levels.
  • Orthogonal to evidence_source: an RCT and a case series are both HUMAN_CLINICAL.
  • Distinct from SEPIO/Sieve's evidence_strength (continuous float, not bound to a scheme).
  • Source quality and per-claim interpretation are separable axes (celiac ZED1227 example).

Summary
  • Three confirmed, non-interoperable evidence models: DisMech, SEPIO/Sieve, koza ingests.
  • Two directions: SEPIO-aligned (graph) and shared flat microschema (import).
  • A and B interoperate via a linkml-map: the microschema is a strict subset of SEPIO — one evidence line, or N independent n-of-1 lines.
  • Migration mechanism (LinkML import by URL) is proven; a DisMech PoC scopes the change.
  • evidence_level is an open, orthogonal question (dismech #5000).
